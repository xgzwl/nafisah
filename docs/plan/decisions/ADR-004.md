# ADR-004: 写信与聊天落在既有 letters.html，不新增第 8 页

## Status: Accepted (2026-11-26)；v1.1.0 修订 (2026-11-26)，修订依据见 ADR-006

## Background
站点硬约束要求 7 页 header/footer 逐字一致、三语字典与 `?v=` 版本串三件套同步。新增页面会把同步面从 7 扩到 8，并新增导航 key，放大回归风险。

## Decision
在 `letters.html` 内增加「写信」与「聊天」两个 section；页面数保持 7，header/footer 一字节不改；只升级 7 页共 14 处版本串到 `20261126a`。EdgeOne 单链路下后端与静态页同源同部署，前端按 ARCHITECTURE §6.2 直接初始化（单次后端可用性自检），不再有 ESA 侧隐藏区块/静态说明的降级分支。

## Consequences
正面：改动面最小、单链路静态部分一致、初始化逻辑集中在一个文件。
负面：`letters.html` 的 JS 加载量增加，用 `defer` 延后初始化缓解；若功能复杂度继续上升，应重新评估拆页并同步全部约束。

## Evidence
- `AGENTS.md:24-36`：7 页 header/footer 逐字一致 + i18n 三件套 + `?v=` 版本串
- `ARCHITECTURE.md` §6：ESA 下线，EdgeOne 单链路
