# ADR-005: 聊天首版采用 SSE 传输，不退化为整段 JSON

## Status: Accepted (2026-11-26)

## Background
PRD 早期版本把「流式逐 Token 打字机渲染」列为 Out-of-Scope，与 agent skill 的 SSE 推荐约定、强制心跳与中止入口产生表观冲突。需要区分「协议层流式」与「效果层打字机动效」，并给出首版确定结论。

## Decision
首版即 `POST /chat` 返回 `text/event-stream`：`ai_response` 增量事件、5s `ping`、`X-Accel-Buffering: no`、四响应头、`[DONE]` 收尾。Out-of-Scope 只覆盖效果层——不人为加 delay、不逐 token 触发读屏播报；流式期间输出节点 `aria-live="off"`，`[DONE]` 后一次性播报。即使未来改为整段 JSON，只要端点仍在 `agents/` 下，`makers-conversation-id` 头依然必发（Critical Rule 5 无条件生效）。

## Consequences
正面：冷启动 10s+ 有心跳可区分「预热中/已断开」；停止按钮可真正中止上游生成并停止计费；与平台统一事件协议一致，后续加 `usage` / `suggest_actions` 不需换协议。
负面：前端需实现 SSE 读取器、`[DONE]` 判定、截断流重试、中止分支（约 150 行 JS），比整段 JSON 多一层状态机。该成本已被 UIUX 状态机吸收，不额外增加设计面。
