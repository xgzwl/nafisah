# ADR-003: 聊天用无框架 LLM 代理，不引入 DeepAgents 全量栈

## Status: Accepted (2026-11-26)

## Background
需求是「主角在线聊天」——单角色、单轮流式回复、客户端持有短历史。DeepAgents/LangGraph 提供子代理、工具循环、上下文压缩、checkpointer，本站一个都不用；引入会增加依赖、`agents.framework` 配置与 peer dep 生产缺失风险。

## Decision
`agents/chat/index.ts` 直接 `fetch(env.AI_GATEWAY_BASE_URL + '/v1/chat/completions', { stream: true })`，用 `agents/_shared.ts` 的 `createSSEResponse` 包装；不设置 `agents.framework`；不读 `context.tools` / `context.sandbox`。

## Consequences
正面：依赖面最小、构建最快、无 peer dep 陷阱、产物可预测。
负面：控制台显示通用框架图标；若未来要工具调用或跨设备续聊，需重新引入框架或扩展代理层，届时另起 ADR。

## Evidence
- `makers-migration/references/api-route-to-makers.md:63-112`：无框架直连网关 + createSSEResponse 骨架
- `makers-agents/SKILL.md:385-391`：peer dep 按 package.json 声明解析的生产陷阱
