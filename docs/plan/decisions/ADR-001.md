# ADR-001: 使用 Blob 而非 KV 作为信件存储的唯一后端

## Status: Accepted (2026-11-26)

## Background
需要持久保存用户提交信件并支持列表分页。平台官方声明无托管数据库；KV 仅用于 Edge Functions（V8）且 ≤25 MB，Blob 用于 Cloud Functions（Node）且免费层 1 GB。聊天端点必须在 Node 侧直连 LLM 网关，运行时需统一。

## Decision
选 Blob（`@edgeone/pages-blob@^0.0.14`），store `nafisah-letters`，一信一 key（`letters/<invertedTs>-<rand>.json`），所有 store 用 `getStore({ name, consistency: "strong" })`。倒排时间戳定宽补零使字典序即新→旧。

## Consequences
正面：并发追加无覆盖（无读改写）、写完即读可见、容量充足、与 agent 同运行时。
负面：需要 `installCommand` 与锁文件；`list` 在千级 key 以上是元数据 O(n)，超过约 2000 封要换游标分页；strong 读略增延迟（正确性优先）。

## Evidence
- `makers-storage/SKILL.md:18`：无托管数据库，Blob 即数据库
- `makers-storage/SKILL.md:30-31`：KV/Blob 运行时与容量分野
- `makers-storage/references/blob.md:18-20`：consistency strong 铁律
- `makers-storage/references/blob.md:62-65`：增长型/并发数据用一文件一记录
