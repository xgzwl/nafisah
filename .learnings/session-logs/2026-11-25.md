# 2026-11-25 会话沉淀 · Tom Riddle 三语粉丝站

## 新坑
- Wikimedia Commons 缩略图只接受白名单宽度，任意宽度（如 800px、1400px）返回 HTTP 400 Use thumbnail sizes listed。可用 1280px、1920px。
- Python urllib 访问 GitHub、Unsplash、Commons API 时 SSL 握手间歇性失败；同一 URL 重试可达。批量下载必须带重试，不能一次失败就判能力不足。
- Google Fonts CSS 在旧 UA 下返回 TTF，现代 Chrome UA 才返回 woff2。字体本地化必须显式带完整 Chrome UA。
- LXGW WenKai 官方 webfont 拆成 97 个分片，整包下载不现实；按站点实际汉字反查 unicode-range，只取命中分片（本次 21 个，约 1.1MB）。
- 浏览器默认请求 favicon.ico，静态站若未提供会产生 404 日志噪声。内联 `<link rel="icon" href="data:,">` 可消除。

## 复踩
- 配置字段不能照搬子代理输出。EdgeOne 官方字段为 outputDirectory / headers，不存在 deployOptions.distPath；ESA 的 notFoundStrategy 仅 singlePageApplication 或 404Page。写配置前必须查官方文档原文。
